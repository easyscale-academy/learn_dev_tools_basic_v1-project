## 4. Coding Agent 到底是什么, 为什么它不只是聊天机器人

你可能已经见过 Claude, ChatGPT 这类聊天机器人: 你打字问问题, 它打字回答, 仅此而已. Coding agent 表面上听起来像是聊天机器人的一个特殊分支, 专门用来聊代码问题, 但这个印象是错的.

Coding agent 和聊天机器人的本质区别只有一条: 聊天机器人只能说, coding agent 能做. 你告诉聊天机器人帮我把这个文件里的某个词改掉, 它顶多告诉你应该怎么改, 剩下的还是你自己动手. 你告诉 coding agent 同一句话, 它会真的打开那个文件, 找到那个词, 改掉, 保存, 你只需要检查结果对不对.

这也是这门课从 mise 到 VS Code 一路铺垫的原因: mise 让 AI 能装工具, Terminal 让 AI 有地方跑命令, VS Code 的集成终端让 AI 就在你眼皮底下干活, GitHub Desktop 给你一颗后悔药. 这些都是给 coding agent 搭的舞台, 让它真正能干活, 而不是纸上谈兵.

叫它 coding agent, 是因为它最早是为写代码设计的, 但它能做的事情早就超出写代码了: 整理文件, 批量改名, 写文档, 甚至操作你电脑上的其他软件. 更准确的叫法应该是万能 agent, 一个能替你干活的助手, 只是行业里习惯了 coding agent 这个名字. 记住这一点, 你会发现这门课后面要学的每一件事, 说到底都是在给这个万能 agent 铺路.

## 8. 导师寄语

**为什么这个练习重要:**

很多人第一次接触 coding agent, 会下意识把它当成一个更聪明的聊天机器人来用: 问它问题, 抄它的答案, 自己动手改. 这样用, 你只用到了它一小部分能力. 它真正的价值在于放手让它干活, 你负责说清楚要什么, 检查结果对不对.

**关键洞见:**

- coding agent 这个名字带来一个误解, 让人以为它只服务于写代码; 实际上它是一个万能 agent, 前面装的每一件工具都是为了让它能真正动手
- 遇到不会注册, 不会基本操作这类前置问题, 优先去找专门讲这个的资料, 而不是指望这门课顺带教
