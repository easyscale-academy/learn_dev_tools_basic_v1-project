# 认识 Coding Agent 验收

## 1. 目标

读完 README, 搞清楚 coding agent 和聊天机器人的本质区别是能不能干活. 这个 Task 本身没有动手练习, 但如果你还没有能用的 AI 产品账号, 或者还不会基本操作 coding agent, 得先去把 README 里指路的两份外部资料过一遍, 补齐这两块前置技能, 后面的 Task 才走得下去.

---

## 2. 要做的事情

1. 读完 README 第 4 节, 能用自己的话说清楚 coding agent 和聊天机器人的区别
2. 检查自己有没有一个能用的 AI 产品账号, 没有的话跟着 [美国 AI 产品注册与订阅指南 (个人版)](https://offer-forge-public.easyscalecloud.com/projects/offer_forge_blogs/blogs/3pVkdtyRVJpyHsff/index.html) 注册并订阅好
3. 检查自己会不会基本操作至少一个 coding agent, 没学过的话跟着 [learn_ai_agent_desktop_app_basic-project](https://github.com/easyscale-academy/learn_ai_agent_desktop_app_basic-project/tree/01-readup) 从头学一遍

**预计用时:** 15 到 30 分钟 (已经有账号且会基本操作的话, 只读不做 5 到 15 分钟)

---

## 3. 检查清单

- [ ] **概念清楚**: 你能说清楚 coding agent 和聊天机器人的本质区别是能不能干活
- [ ] **账号就绪**: 有一个能正常使用的 AI 产品账号
- [ ] **基本操作过关**: 能打开一个 coding agent, 和它对话, 并看懂它做了什么
- [ ] **知道去哪补课**: 知道注册指南和外链课程分别在哪, 需要时能自己回去看
