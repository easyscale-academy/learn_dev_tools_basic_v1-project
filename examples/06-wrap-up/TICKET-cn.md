# 回顾这门课并跑通完整工作流

## 1. 目标

这个 Task 不再学新东西, 而是把前面几个 Task 的收获串成一条线, 并且真正跑一遍完整的工作流, 证明这些工具确实能配合起来干活, 而不是各自孤立的知识点.

---

## 2. 要做的事情

1. 读完 README 第 4 节, 能用自己的话说清楚这门课其实在讲同一件事
2. 对照第 5 节, 确认自己确实能做到列出来的那几件事
3. 按第 6 节的步骤, 打开一个项目, 用 coding agent 改一个字, 再检查改动
4. 通读第 7 节, 挑一个自己感兴趣的方向, 记下关键字

**预计用时:** 15 到 30 分钟

---

## 3. 检查清单

- [ ] **说得清主线**: 你能说清楚 mise, Mac 三件套, VS Code, coding agent 这几课其实是在讲同一件事, 而不是四个孤立的知识点
- [ ] **环境齐全**: 本地 (或 Codespace) 有一套能用的开发环境, mise, VS Code, Terminal, GitHub Desktop 都在
- [ ] **账号和基本操作都就绪**: 有能用的 AI 产品账号, 并会基本操作至少一个 coding agent
- [ ] **跑通完整工作流**: 真的完成过一次打开项目, 复制路径, 让 AI 改一个字, 再检查改动的完整流程
- [ ] **会用后悔药**: 知道改坏了去 GitHub Desktop 的 History 找回来
- [ ] **记下了一个方向**: 从第 7 节里挑了一个感兴趣的方向, 记下了对应的关键字
