# 在 VSCode 中打开项目并掌握文件路径

## 1. 目标

学会把 VS Code 当作文件管理工具来用, 而不是代码编辑器. 完成这个 Task 之后, 你应该能不假思索地打开任意一个项目文件夹, 找到你想要的文件, 并把它的完整路径交给 AI, 同时知道怎么打开集成终端. 这是后面所有和 AI 协作改文件的基础, 跳过这一步会让后面每次都卡在说不清要改哪个文件上.

---

## 2. 要做的事情

1. 在 VS Code 里打开一个项目文件夹, 比如用 GitHub Desktop clone 下来的一个仓库
2. 右键点击三个不同的文件, 分别选择 Copy Path, 把路径粘贴到笔记里
3. 用 `Cmd + P` 搜索三次, 每次输入不同文件名的一部分并打开对应文件
4. 打开任意一个文本文件, 做一个小改动, 用 `Cmd + S` 保存
5. 用 `` Ctrl + ` `` 打开集成终端, 输入 `pwd` 确认它停在当前项目文件夹里

**预计用时:** 15 到 30 分钟

---

## 3. 检查清单

- [ ] **能打开项目**: 独立打开任意一个文件夹, 左侧出现文件树
- [ ] **能复制路径**: 至少 3 次右键 Copy Path, 并能看懂复制出来的路径长什么样
- [ ] **能快速搜索**: 用 `Cmd + P` 在 5 秒内找到指定文件, 完成至少 3 次
- [ ] **能编辑并保存**: 打开一个文件做小改动, 用 `Cmd + S` 保存, 标签页上的圆点消失
- [ ] **能打开集成终端**: 用 `` Ctrl + ` `` 打开集成终端, 并确认 `pwd` 显示的是当前项目文件夹
- [ ] **说得清为什么**: 你能解释清楚为什么复制文件路径这个动作对和 AI 协作很重要
