# 开发者工具基础系列索引

这门课教你搭好开发者工具的地基: 一套统一管理工具版本的方法, 一套本地开发环境, 以及怎么用这些工具搭一个舞台, 迎接真正能干活的 coding agent. 下面按分组列出这几个 Task, 按顺序读效果最好, 但不是必须. 每个 Task 相对独立, 你也可以只挑自己缺的那一块去看.

## 1. 打地基, 把本地开发环境装起来

先解决工具版本混乱的问题, 再把开发的主战场从云端搬到你自己的 Mac 上.

- [02-install-mise](../02-install-mise/README-cn.md): 在 GitHub Codespace 里装好 mise, 这是你用来管理几乎所有开发工具的万能遥控器
- [03-mac-quick-setup](../03-mac-quick-setup/README-cn.md): 在 Mac 上装好 VS Code, Terminal, GitHub Desktop 三件套, 顺带学会 Terminal 的基本用法

---

## 2. 学会用 VS Code 当你和 AI 沟通的桥梁

装好了工具, 接下来学怎么用它们和 AI 协作, 而不是自己动手改代码.

- [04-open-github-repo-in-vscode](../04-open-github-repo-in-vscode/README-cn.md): 打开一个项目文件夹, 学会复制文件路径和打开集成终端, 这是你和 AI 沟通的共同语言

---

## 3. 认识你的 coding agent

前面几课攒的工具, 都是在给这一课要介绍的东西搭舞台.

- [05-learn-coding-agent](../05-learn-coding-agent/README-cn.md): 说清楚 coding agent 其实是一个能干活的万能 agent, 不只是聊天机器人, 并指路补齐注册账号和基本操作这两块前置技能

---

## 4. 收尾

- [06-wrap-up](../06-wrap-up/README-cn.md): 回顾整门课学到了什么, 现在能做到什么, 以及往后可以继续深挖的几个方向

---

## 5. 小结

这几块合起来, 是搭好开发者工具地基所需要的东西. 按顺序读下来效果最好, 但如果你已经会了某一块, 直接跳过, 挑自己缺的那几个 Task 看就行. 最后一个 Task 会带你回顾整门课, 并指几个可以继续深挖的方向.
