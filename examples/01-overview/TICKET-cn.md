# 读完系列索引

## 1. 目标

这个 Task 就是读一遍系列索引, 拿到整门课的地图, 并决定自己从哪儿开始. 没有产出物, 也没有要跑的命令.

---

## 2. 要做的事情

1. 通读本 Task 的 README, 把这门课分成哪几块过一遍
2. 按顺序从下一个 Task 开始, 或者挑一条和自己最相关的线开始

**预计用时:** 5 到 15 分钟

---

## 3. 检查清单

- [ ] **知道怎么分块**: 你能说出这门课分成打地基, VS Code 协作, 认识 coding agent, 收尾这几块, 每块解决什么
- [ ] **知道从哪开始**: 你能说出自己打算从哪个 Task 开始, 以及为什么
- [ ] **知道终点在哪**: 你能说出收尾 Task 排在最后, 读完它才算学完整门课
