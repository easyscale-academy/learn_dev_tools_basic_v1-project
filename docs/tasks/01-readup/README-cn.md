# 开发者工具基础 总览

> 一句话: 这门课教你搭好开发者工具的地基, 并给 coding agent 搭好能干活的舞台. 想先了解全貌, 看 [README-ORIGINAL-cn.md](README-ORIGINAL-cn.md).

## 1. 这门课是什么

这门课教你从零装好一套本地开发环境, 再学会怎么把它交给一个真正能干活的 coding agent. 不需要你先会编程.

这是一个 readup 类型的教学仓库: 整个 repo 就是一门课, 内容拆成 [examples/](examples/) 下一个个按编号排列的 Task. 你不用把它当成一本从头读到尾的大部头, 只要照下面 "怎么读" 的路子, 一篇篇顺着读下来, 边读边照每篇的 TICKET 做, 就能学会.

---

## 2. 怎么读

1. 进 [examples/](examples/), 从 01 开始按编号往下读. 第一篇是索引, 会给你整门课的地图.
2. 每个 Task 目录里, 先读 README (这一篇教什么, 带你做什么), 再照它的 TICKET 把 "要做的事情" 逐项做完, 用 "检查清单" 自查是不是真的做到了.
3. 一篇读完再读下一篇, 直到读完最后一篇 (它会帮你梳理学到了什么, 并指出想更进一步可以往哪走).
4. 读到什么算成: 每个 Task 的 TICKET 检查清单都能逐项打勾, 且能不看教程自己把核心流程走一遍.

---

## 3. 读完你能做到什么

你会有一套从零搭好的本地开发环境, 会用 Terminal 和 VS Code 精确地告诉 AI 要改哪个文件, 也清楚去哪补齐账号和基本操作这两块前置技能, 让自己随时能上手用 coding agent 干活.
