# 完成开发者工具基础全部课程

## 1. 目标

读完这门课全部 Task, 你要在自己的电脑上 (或 GitHub Codespace 里) 真正装出一套能用的开发环境: mise 管好工具版本, VS Code 加 Terminal 加 GitHub Desktop 三件套装齐, 并且知道怎么把这套环境交给一个 coding agent, 让它替你干活, 而不是停留在读完了但没跑起来的状态.

---

## 2. 要做的事情

1. 先读根目录的 README, 明白这门课怎么读.
2. 进 examples, 从 01 开始按编号往下读, 第一篇会给你整门课的地图.
3. 每篇先读 README 再照它自己的 TICKET 逐项做完并确认.
4. 读完最后那个收尾 Task, 想清楚自己学到了什么, 以及下一步可以往哪走.

**预计用时:** 95 到 195 分钟 (约 1.5 到 3.5 小时)

---

## 3. 检查清单

- [ ] **全部 Task 完成**: examples 下每个 Task 的 TICKET 检查清单都已逐项打勾.
- [ ] **能独立复现**: 不看教程, 能把这门课的核心流程从头独立走一遍.
- [ ] **能讲清概念**: 能用自己的话解释这门课几个核心概念各自解决什么问题.

---

## 4. 关键能力

- 会用 mise 统一管理 Python, Node.js 等开发工具的版本, 不用分别学多个各自为政的版本管理器
- 在 Mac 上从零装好本地开发环境: VS Code, Terminal (或 Ghostty), GitHub Desktop
- 会用 Terminal 的基本命令在文件系统里移动, 理解命令行为什么是开发工具的默认入口
- 会用 VS Code 打开任意项目文件夹, 用 Copy Path 拿到精确的文件路径, 打开集成终端
- 有一个能用的 AI 产品账号, 并会基本操作至少一个 coding agent
- 说得清 coding agent 和聊天机器人的本质区别: 能干活, 不是能聊天
- 能跑通一次完整工作流: 打开项目, 复制路径, 让 coding agent 改文件, 用 GitHub Desktop 检查或撤销改动
- 遇到教程没教的细节, 知道带着具体场景去问 AI, 而不是死磕文档
